# 仅有效表面/像素的 mesh 评估（v2）

本协议覆盖原有评估分数；源 mesh、相机、颜色场和渲染缓存保留。`background/report.md` 为 mask 外纯背景；`recomposition/report.md` 为背景 + MV-SAM3D 组合 mesh。

1. **比较范围**：按本轮开始时已完成的 mesh 建立每场景固定方法集合。主表使用该集合所有方法共同覆盖的区域；同时报告每种方法自身覆盖区域的分数。未完成的 mesh 不算 0 分，也不参与该场景交集；结果记录方法集合。各方法自身覆盖域不同，其分数不应直接作为同面积排名。
2. **像素有效性**：使用真实三角网格的射线命中深度，`isfinite(depth) & depth>0` 判断有效，不用 RGB 是否黑色判断。纯背景再与目标 mask 的补集取交；组合 mesh 保留物体像素。共同评估 mask 是这些有效 mask 的交集。空洞、未覆盖像素和纯背景目标 mask 内的像素完全不进入评分分母。
3. **图像指标**：PSNR 使用有效像素的真实 RGB MSE，不把其他区域清零后除以整图面积。SSIM 的 11×11、sigma1.5 高斯局部均值/方差只由有效像素贡献，并重新归一化窗口权重；LPIPS-VGG0.1 spatial 的两个输入在无效区域填同样的零 RGB，距离图只在有效区域平均。主表与自身覆盖域分别计算。没有共同像素的视角标为不可评分，不记0分。
4. **几何参考**：COLMAP 原始稀疏点云，至少两个非 test* 观测；背景参考点要求目标 mask 票数比例 ≤0.1，且只取已声明共同 ROI。它不是独立扫描真值，也不包含原先被物体遮挡的补全面真值。
5. **只比较有表面的几何**：使用参考点在共同评估相机中的真实 COLMAP 特征轨迹。仅当该真实观测像素在有效覆盖范围内才纳入参考点；每个参考点按 seed0 固定选择一个合格观测，最多100000点。用该像素的 mesh 深度反投影，获得每个方法的对应表面样本；所有方法用同一组参考点、相机、像素。自身覆盖域几何也另算。没有按三维误差、最近距离、F1 阈值或深度接近程度预筛点；深度错误和错误物体位姿仍会降低指标。
6. **CD 与 F1**：CD-L1 = 0.5×(预测表面样本→参考点的平均最近距离 + 参考点→预测表面样本的平均最近距离)。Precision = 预测样本中最近参考点距离≤τ的比例；Recall = 参考点中最近预测样本距离≤τ的比例；F1=2PR/(P+R)，P+R为0时F1为0。共同训练相机半径定义为 R=1.1×max‖相机中心−训练相机中心均值‖，报告 τ=R 的0.5%、1%、2%，主表使用1%。阈值、Precision、Recall、采样数均保存。单位为 COLMAP 单位，没有假定米/厘米，不做各方法独立 ICP 或缩放。
7. **含义**：这是有表面条件下的精度与参考点匹配率，不惩罚被排除的空洞，不能解释为完整场景重建完整度。稀疏点密度仍会影响 F1/CD，不能与 DTU/T&T 的扫描真值指标直接混比。报告同步列出共同像素比例、各自覆盖率以及有效参考点比例。
8. **固定渲染和外观**：原始三角形、CPU Open3D/Embree 射线求交、1/4 分辨率、COLMAP 内外参、像素中心 x+0.5/y+0.5。颜色场为统一 VM-SH：256 网格、rank16、SH2、MSE+TV、5000步、每步8192射线；只学颜色、不更新 mesh 或 3DGS。已完成颜色场/渲染直接复用。这是 MILo 思路的轻量适配，非官方3000网格/整图训练协议。原生顶点色或 MV-SAM3D UV 纹理分数另列，不与无纹理导出强行混算。
9. **数据状态与划分**：使用原始有物体图像的共同 1/8 留出列表；数据集无物体 test* RGB 不作为组合 mesh 真值。已有 PaintMesh 几何和生成证据可能使用过这些相机，因此这是已有结果审计，不是严格相同训练划分的论文复现。
10. **聚合与执行**：逐视角平均后逐场景平均；五方法主均值只用五方法均完成且可评分的共同场景，几何均值使用相机半径归一化 CD。CPU 一次一个网格/支持域任务；每卡最多一个外观/指标任务，启动要求空闲显存≥10000MiB，评估进程显存上限3072MiB，不停止其它训练任务。

文献依据：[From Blobs to Spokes（包含虚拟扫描和 F1 评估）](https://arxiv.org/html/2604.07337v1)、[MILo 官方 mesh_nvs](https://github.com/Anttwo/MILo/tree/master/milo/eval/mesh_nvs)。这里按用户要求排除未覆盖区域，与论文用于衡量完整度的原始 MBR 全图指标不同。
